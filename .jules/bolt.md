## 2024-05-18 - Zustand Selector Refactoring Caveats
**Learning:** When extracting inline UI sections into isolated child components (e.g., `ProgressBar` from `GlobalPlayerBar`) to prevent parent re-renders due to high-frequency state updates from Zustand, it is critical to ensure that all local event handlers (like `handleSeek`) are also moved or passed down. Failing to do so leaves orphaned function calls and results in runtime `ReferenceError`s. Also, using string replacements to refactor complex component logic requires extreme care to avoid duplicating code blocks.
**Action:** When extracting child components for optimization, meticulously review all JSX attributes (like `onClick`) and move their corresponding handler definitions into the child component (or pass them as props). Before completing a refactor, manually verify the parent component to ensure no dead or undefined variables/functions remain.
