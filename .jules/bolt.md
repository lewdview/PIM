## 2024-05-18 - Isolated High-Frequency Subscriptions in GlobalPlayerBar
**Learning:** Extracting UI sections that rely on frequently updating Zustand properties (like progress and currentTime) into isolated child components effectively prevents massive re-renders of the parent component during high-frequency events (like timeupdate). Avoiding destructuring alone is not enough if the parent component still explicitly subscribes to those properties.
**Action:** Always create small, isolated child components for UI elements dependent on fast-updating state values (e.g., progress bars, time displays) rather than subscribing the large parent component. Ensure all dependent helper functions and variables (like handleSeek, effectiveDuration) are moved alongside the JSX to prevent ReferenceErrors.
