## 2024-05-18 - [Fix hardcoded admin passphrases in statically bundled frontend]
**Vulnerability:** A hardcoded plaintext administrator passphrase ('th3scr1b3') was present in the frontend React components (`AdminPage.tsx` and `BeatmapEditor.tsx`) for gating access to sensitive panels.
**Learning:** Vite bundles code statically for the client. Any hardcoded secrets, passphrases, or sensitive strings in source code become readable in the production JavaScript bundles exposed to end-users via the browser. This allows malicious actors to easily inspect the bundle, find the string, and gain unauthorized access to administrative functionality.
**Prevention:** Never hardcode plaintext secrets in frontend code. If client-side gating is required, utilize client-side hashing algorithms like `crypto.subtle.digest('SHA-256')` to validate user input against a hardcoded hash, rather than comparing plaintext values. If a backend API requires the plaintext password, store it transiently in `sessionStorage` only after a successful hash validation by the user.
