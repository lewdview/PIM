## 2023-11-20 - Fix Hardcoded Admin Passphrase Vulnerability
**Vulnerability:** A hardcoded plaintext admin passphrase (`th3scr1b3`) was used for frontend authentication gating in `src/pages/AdminPage.tsx` and `src/pages/BeatmapEditor.tsx`. Additionally, it was passed as plaintext in automatic backend sync logic (`supabase.functions.invoke`) in `src/utils/adminConfig.ts`.
**Learning:** Client-side authentication gates must use hashing (e.g., Web Crypto API SHA-256) instead of plaintext comparison. Furthermore, automated backend scripts cannot securely rely on hardcoded secrets on the client side; these actions must fallback to manual user-prompting to avoid exposing credentials. Storing credentials insecurely in `sessionStorage` for automated actions is also an anti-pattern.
**Prevention:** Do not hardcode authentication credentials. For frontend-only gating, compare hashes. Ensure automatic processes requiring credentials are removed or refactored to require manual input to prevent secret exposure in source code.
