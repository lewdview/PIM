## 2024-05-18 - Hardcoded Admin Passphrase in Client Bundle
**Vulnerability:** A plain text admin passphrase (`th3scr1b3`) was hardcoded directly into the frontend components (`AdminPage.tsx` and `BeatmapEditor.tsx`) to gate access. In Vite applications, hardcoded strings and `VITE_` prefixed environment variables are statically injected and visible in the public client bundle source code.
**Learning:** We must not rely on simple string comparisons for sensitive authentication on the frontend. While the backend functions properly authenticated the request, an attacker could easily extract the plaintext passphrase and pass it. To maintain functionality without major backend architectural changes, the plain text credential can be hashed on the frontend (using Web Crypto API SHA-256) for the initial UI gate, but unfortunately must still be persisted (e.g. in `sessionStorage`) to pass to the backend.
**Prevention:** Avoid defining plain text credentials in frontend codebases. For simple frontend gates, utilize one-way hashing techniques on inputs and compare them against a hardcoded hash, rather than comparing against a hardcoded plaintext secret. Ensure backend services are properly authenticating and authorizing requests.
