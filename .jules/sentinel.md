
## 2025-02-27 - Hardcoded Admin Passphrase Removal
**Vulnerability:** A critical vulnerability where a hardcoded admin passphrase was embedded in the client-side frontend bundle within `src/pages/AdminPage.tsx` and `src/pages/BeatmapEditor.tsx`.
**Learning:** Storing secrets or administrative passwords directly in the source code exposes them to anyone who examines the client bundle. This happens frequently when creating simple gating mechanisms on the frontend without a dedicated backend auth route.
**Prevention:** For client-side-only authentication gates, developers should rely on cryptographic hashes. Use `window.crypto.subtle.digest` to evaluate entered passphrases against a stored hash value (e.g., SHA-256) instead of keeping the raw secret exposed in the JS bundle. If background services strictly require the raw passphrase payload, store it temporarily in `sessionStorage` post-authorization.

## 2025-02-27 - Safe sessionStorage Fallbacks for Hardcoded Secrets
**Vulnerability:** A critical vulnerability where a hardcoded admin passphrase was embedded in `src/utils/adminConfig.ts`. The codebase exposed `'th3scr1b3'` when invoking a Supabase Edge Function to sync the configuration.
**Learning:** Storing authentication passphrases directly in client-side utility functions or component state exposes them to users. If background edge functions require these passphrases, you must remove them from the codebase entirely and pass them dynamically instead (e.g. from `sessionStorage`). Moreover, when accessing browser APIs like `sessionStorage` in utility files outside of React components, you must wrap them with a safety check (`typeof sessionStorage !== 'undefined'`) to prevent `ReferenceError` crashes during SSR or build pipelines.
**Prevention:** Eliminate hardcoded secrets from client bundles. Utilize `sessionStorage` with safe browser checks (`typeof sessionStorage !== 'undefined' ? sessionStorage.getItem('SECRET_KEY') || '' : ''`) when edge functions expect dynamic credentials previously stored by frontend login pages.
