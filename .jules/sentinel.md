## 2025-02-13 - Hardcoded Admin Passphrase Removal
**Vulnerability:** A hardcoded plaintext admin passphrase (`th3scr1b3`) was used to authenticate on the frontend and injected directly into the frontend bundle in `src/pages/AdminPage.tsx` and `src/pages/BeatmapEditor.tsx`. It was also being sent directly in backend API payloads in `src/utils/adminConfig.ts`.
**Learning:** For frontend-only gating, comparing user input against a hardcoded plaintext credential exposes the system to trivial bypasses if the source code is inspected. While generally insecure, backend functions requiring plaintext passphrases should receive them securely, not by exposing the key globally.
**Prevention:** Use client-side Web Crypto API to hash inputs (`crypto.subtle.digest('SHA-256', ...)`) and compare against a stored hash instead. To satisfy backend utility functions (e.g. `supabase.functions.invoke`), cache the successfully verified plaintext input dynamically into `sessionStorage`, ensuring it is never hardcoded in source files.
