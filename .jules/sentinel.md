## 2024-05-18 - Hardcoded Admin Passphrase in Frontend Bundle
**Vulnerability:** The admin authentication passphrase was stored in plaintext directly within the frontend source code (`src/pages/AdminPage.tsx` and `src/pages/BeatmapEditor.tsx`), making it trivial to extract from the client-side bundle. Additionally, it was hardcoded in API requests to the backend.
**Learning:** Hardcoding secrets or credentials in frontend environments is fundamentally insecure because any client-side code is publicly accessible to users. Frontend-only gating mechanisms should avoid exposing raw credentials.
**Prevention:** Avoid embedding sensitive information such as plaintext passwords or API keys in frontend code. Instead, use client-side hashing (e.g., Web Crypto API SHA-256) to verify user input against a hardcoded hash, and securely store the plaintext input dynamically (like in `sessionStorage`) only upon successful authentication, ensuring it is passed securely to backend services without exposing the actual credential in the bundle itself.
