## 2024-05-24 - Hardcoded Admin Passphrase in Sync Function
**Vulnerability:** Found a hardcoded plaintext admin passphrase (`th3scr1b3`) in `src/utils/adminConfig.ts` within the `saveAdminConfig` function.
**Learning:** Hardcoding secrets like passphrases in frontend source code exposes them to anyone who inspects the client bundle, allowing malicious actors to bypass authentication checks or invoke backend functions with elevated privileges. The memory explicitly states: "When fixing client-side security issues (like removing hardcoded secrets), do not blindly remove required authentication payload properties (e.g., `passphrase`) from backend API invocations without also updating the corresponding edge functions, as this will result in rejected requests and broken functionality. ... backend API calls requiring the plaintext passphrase must include a fallback (e.g., `prompt()`) to handle page reloads that clear the ephemeral state."
**Prevention:** Do not hardcode secrets in client-side code. If an ephemeral passphrase is required by a backend function, prompt the user for it if it's not present in the current session.
