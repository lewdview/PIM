## 2025-02-14 - Fix Hardcoded Admin Passphrase Vulnerability
**Vulnerability:** A hardcoded plaintext admin passphrase (`th3scr1b3`) was found directly in the Vite client bundle for gating UI access and authorizing backend edge function updates (`updateAdminConfig`).
**Learning:** Hardcoded credentials in client bundles are fully exposed to anyone viewing the source. However, since the edge function validation strictly required the plaintext passphrase and could not be rewritten, client-side auth state needed a secure fallback.
**Prevention:** For UI gating, use the Web Crypto API (`crypto.subtle.digest`) to hash user input on the client and compare it to a hardcoded SHA-256 hash. If the plaintext string is strictly required for backend validation (e.g., in auto-sync utils like `adminConfig.ts`), store the plaintext ephemeral credential securely in `sessionStorage` upon initial successful login. This prevents storing it in source control while avoiding UX-breaking `prompt()` loops on automated requests.
