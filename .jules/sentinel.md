## 2025-02-14 - Hardcoded Admin Passphrase in adminConfig.ts
**Vulnerability:** A hardcoded plaintext admin passphrase ('th3scr1b3') is used when syncing configuration to the backend via Supabase Edge Functions in `src/utils/adminConfig.ts`.
**Learning:** Hardcoded secrets in client-side code can be trivially extracted by end users, allowing them to bypass authentication and execute unauthorized actions (like updating admin configs). When backend functions require auth, the credentials must be dynamically retrieved (e.g., from an environment variable on the server, or securely provided by the user and stored temporarily in memory/session).
**Prevention:** Never hardcode passwords, passphrases, or API keys in the source code. For client-side admin tools that interface with secure backend functions, prompt the user for the passphrase and store it securely (e.g., `sessionStorage`) to pass along with the request.
