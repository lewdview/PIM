## 2023-10-27 - Replace Hardcoded Passphrase with Secure Hashes
**Vulnerability:** A plaintext admin passphrase ('th3scr1b3') was hardcoded directly into the frontend React components (`AdminPage.tsx` and `BeatmapEditor.tsx`), allowing any user inspecting the bundle to access restricted admin views and bypass frontend authorization.
**Learning:** Hardcoding plaintext credentials on the client-side fundamentally breaks zero-trust models. Even though the application interacts with server-side validations via edge functions (which strictly require the plaintext passphrase for specific configurations like `updateAdminConfig`), the frontend gating should not rely on an embedded plaintext password. Furthermore, removing the plaintext without preserving the state for the backend utility integration breaks the flow.
**Prevention:** Store a cryptographically secure hash (e.g., SHA-256) of the credentials in the client application to compare against user input. While client-side gating alone is weak, avoiding hardcoded secrets drastically raises the bar for unauthorized discovery. Continue to capture and store the necessary ephemeral authentication materials (`sessionStorage`) explicitly upon successful entry to maintain interoperability with dependent backend processes.
