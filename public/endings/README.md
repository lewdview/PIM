Final Bombshell piece for each monthly Playgama build's Bombshell ending.

Name it mMM-final.jpg (or .jpeg/.png/.webp), e.g. m01-final.jpg for January.
The build ships only the current month's piece, re-encoded to at most 1600px wide.
Without one, the Bombshell ending shows the month's full Bombshell gallery instead.
