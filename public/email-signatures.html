How to install in your mail client:

  1. Gmail: Click the "Copy for Gmail / Apple Mail" button above → Open Gmail Settings (Gear icon → See all settings) → Scroll down to Signature → Click + Create new → Click into the signature editor box → Paste (Cmd + V / Ctrl + V) → Scroll to bottom and click Save Changes.
  2. Apple Mail (macOS): Mail → Settings → Signatures → Select your account and click + → Paste into the preview box → Uncheck "Always match my default message font" so your custom Outfit and JetBrains typography displays properly.
  3. Outlook: Settings → View all Outlook settings → Mail → Compose and reply → Paste into signature box → Save.
  4. Superhuman: Hit Cmd + K → Type "Signature" → Paste directly into the editor → Done!
